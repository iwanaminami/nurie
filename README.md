# nurie｜塗るだけ日程調整

ドラッグで塗るだけの日程調整ツールです。候補日と時間をグリッドに塗り、参加者は自分の空きを塗って共有するだけ。アカウント登録は不要で、URLを知っている人だけが調整表に参加できます。

**使ってみる: https://nurie.noweb.page/**

## 特長

- カレンダーと時間グリッドをドラッグで塗るだけの直感的な操作（PC・スマホ対応）
- 2つの調整方法：「時間で調整」（日 × 時間）と「日だけで調整」（日にちのみ）
- 回答は ○（空いてる）/ △（空いてなくはない）/ ×（空いてない）の3段階、一言コメントも付けられます
- 主催者は回答一覧をCSVでダウンロードできます
- ダークモード対応
- 作成した調整表は30日後に自動削除されます

## 使い方

1. 候補日をカレンダーで塗り、時間帯を塗って日程調整を作成
2. 表示されたURLを参加者に共有
3. 参加者は自分の名前で空きを塗って保存
4. 回答一覧で全員の空きが一目で分かります（管理用URLからはCSV出力や参加者の削除もできます）

## 技術構成

- Python 標準ライブラリのみ（フレームワーク・外部依存なし）
- データベース: SQLite
- Docker / Docker Compose で動作

## 自分で動かす

```bash
docker compose up -d --build
# http://localhost:8378 で開けます
```

## プライバシー

- アカウント登録は不要です。保存されるのは名前・空き状況・任意の一言だけです
- 調整表のデータは作成から30日後に自動削除されます
- 稼働中サービスのプライバシーポリシー: https://nurie.noweb.page/privacy

## 開発について

nurie は、Meta のパーソナル AI エージェント **Muse** との対話を通じて、設計・実装・運用を行っています。
